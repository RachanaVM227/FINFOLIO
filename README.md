# 🌍 Global Stock Market Analytics System

A modern full-stack **Global Stock Market Web Application** designed to track, analyze, and visualize worldwide financial markets in real time.

---

# 🚀 Features

## 📈 Market Dashboard
- Real-time global stock tracking
- Interactive charts & analytics
- Market trend visualization
- Top gainers & losers
- Live stock ticker updates

## 🌎 Global Markets Covered
- NYSE
- NASDAQ
- NSE India
- BSE India
- Tokyo Stock Exchange
- London Stock Exchange
- Cryptocurrency Markets

## 📊 Analytics Features
- Histogram market analysis
- Volume tracking
- Stock comparison tools
- Portfolio performance tracking
- AI-based market insights

# 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| React | Frontend Framework |
| TypeScript | Application Logic |
| Tailwind CSS | UI Styling |
| Chart.js / Recharts | Data Visualization |
| Node.js | Backend |
| Express.js | APIs |
| MongoDB / PostgreSQL | Database |
| WebSocket | Real-time Updates |
